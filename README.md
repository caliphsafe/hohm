# HOHM investor & industry partner pitch

Static, responsive pitch page using the original HOHM PACK logo, color system, and locally hosted licensed fonts. No installation or build required. Vercel serves the repository root.

## Files
- `index.html`: 15 narrative chapters, sources, and financial disclosures.
- `style.css`: responsive styling and presentation layout.
- `app.js`: chapter navigation, cost/volume sensitivities, partnership brief dialog.
- `assets/`: original brand SVGs, fonts/licenses, and source presentation imagery.
- `vercel.json`: static hosting configuration and headers.

## Financial methodology
Research reviewed November 23, 2026. Public references are linked in the page; prices are snapshots, not supply quotes. The proposed dry-product pilot is a new planning scenario, not the original bottled-beverage forecast.

Equal SKU mix. DTC 60% / direct wholesale 40%. MSRP $9.99 (4 oz hibiscus) and $16.99 (8 oz baobab). Wholesale realization 60% of MSRP. DTC allowance 2%; wholesale allowance 5%. Target COGS $4.30 and $7.30. Ingredient assumptions $8/lb and $10/lb are unquoted procurement targets. Public-price sensitivity uses $18.22/lb hibiscus and $27.99/2 lb baobab. All non-ingredient cost inputs are illustrative.

Blended net revenue per pouch = 13.49 × (0.6 × 0.98 + 0.4 × 0.6 × 0.95) = $11.00784.
Variable selling costs = 0.6 × (13.49 × 0.029 + 0.15 + 1.50) + 0.4 × 0.35 = $1.364726.
Target contribution = $11.00784 − $5.80 − $1.364726 = $3.843114.
Annual fixed opex = $120,000. At 24,000 units: net revenue $264,188.16; contribution $92,234.736; operating result −$27,765.264. Break-even rounds up to 31,225 pouches. Excludes development expense, finance, depreciation, taxes, and cash timing. DTC postage assumed customer-paid; no distributor layer.

The $200,000 capital envelope is a proposal for discussion, not an owner-approved securities offering or committed financing. No current revenue, contracts, product safety validation, certifications, operating team, or market-size estimate is asserted. Confirm legal entity, team, contact destination, final product strategy, supplier quotes, and monthly cash plan before investor circulation.

## Source review
The source presentation is a December 2014 Fisher College senior project by Nelson Abreu for Seriously Red / Healthy Drink Trends LLC. The workbook labels its values as examples. Original figures are isolated in the page appendix. Cash-flow/payables, payroll totals, chart discrepancies, and loan-term issues are disclosed there. No historical phone or website is reused as HOHM contact information.

## Interaction
Present deck opens chapter controls. Previous / Next or PageUp / PageDown navigate; Escape exits when focus is outside an input or control. Financial controls update the model in the browser. The partnership dialog copies a brief and does not send messages or collect personal data.
